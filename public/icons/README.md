# App Icons Directory

Place your app icon image(s) in this directory.

### Supported / Recommended Filenames:
- **`app-icon.png`** (or **`icon.png`**) — Primary app icon (recommended: 512x512 or 256x256 PNG)
- **`apple-touch-icon.png`** — iOS Home Screen icon (recommended: 180x180 PNG)
- **`favicon.png`** (or **`favicon.ico`**) — Browser tab icon (recommended: 32x32 or 48x48 PNG/ICO)

Files placed inside `public/` are served at the root URL (e.g., `/icons/app-icon.png`).
